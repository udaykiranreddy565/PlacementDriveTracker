# Placement Drive Tracker 📱

A simple mobile application built with **React Native and Expo** to help students track their placement opportunities and job applications.

## 🚀 Features

- **Add Placement Drives:** Enter a company name and job role.
- **Track Application Status:** Mark a placement drive as applied or not applied.
- **Delete Drives:** Remove placement drives from the list.
- **Applied Drive Counter:** View the number of applied drives and total drives.
- **Input Validation:** Prevent adding a drive when either input field is empty.
- **Dynamic UI Updates:** Update the displayed information using React state.

## 🛠️ Tech Stack

- React Native
- Expo
- JavaScript
- React Hooks (`useState`)
- React Native Components (`View`, `Text`, `TextInput`, `TouchableOpacity`, `FlatList`)
- JavaScript Array Methods (`map`, `filter`)

## 📸 Application Overview

The application allows users to enter placement details, view their drives, update application statuses, and delete entries.

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm
- Expo Go on a compatible mobile device, or an appropriate development environment

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/PlacementDriveTracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd PlacementDriveTracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npx expo start
   ```

5. Follow the Expo instructions to run the app on a compatible device or emulator.
